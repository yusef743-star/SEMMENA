# SEMMENA

Jeu de colonisation en ligne pour 3 à 6 joueurs (règles de base + extension 5-6 joueurs avec les pions Menhir).

- 3-4 joueurs : plateau de 19 tuiles, règles de base.
- 5-6 joueurs : plateau agrandi (30 tuiles), deux joueurs actifs par tour grâce aux pions Menhir
  (Menhir 1 : lance les dés et joue normalement ; Menhir 2 : joue ensuite sans dés, sans échange entre joueurs).

## Jouer
1. Un joueur (l'hôte) clique sur « Créer une partie » et partage le code à 5 caractères.
2. Les autres cliquent sur « Rejoindre » et entrent le code.
3. L'hôte lance la partie dès qu'il y a au moins 3 joueurs.

L'hôte doit garder l'application ouverte pendant toute la partie (c'est lui qui fait office de serveur).
Si un joueur perd la connexion, il peut revenir avec le même prénom et le même code.
